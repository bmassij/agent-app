# Cursor-agent: vacatures

Bij elke run:

1. `python3 tools/vacature-agent/vacature_agent.py search`
2. Toon alleen `tools/vacature-agent/data/inbox.md` (pending). Geen afgewezen ruis.
3. Stop. Wacht tot Bart **goed ID** of **niet ID** zegt.
4. `goed`: `python3 tools/vacature-agent/vacature_agent.py goed ID` en toon de brief.
5. `niet`: `python3 tools/vacature-agent/vacature_agent.py niet ID`
6. Nooit solliciteren zonder **goed**.
